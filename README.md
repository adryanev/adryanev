## About me

I build APIs, mobile apps, and the tools that help teams ship and maintain them. My work includes data modeling, performance tuning, observability, and build and release automation.

I prefer clear code and simple designs. I enjoy tracing a production problem to its cause as much as building a new feature.

## Current focus

- Native iOS development with Swift.
- Open source work on CinemataCMS, including media processing and observability.
- Developer tools and automation for everyday workflows.
- Browser games with calm play and touch and keyboard support.
